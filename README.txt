MYWORKLOG PWA V3

This is a real installable PWA, not a file:// HTML app.

Deploy the entire folder to an HTTPS static host such as GitHub Pages or Netlify.
Then open the HTTPS address on Android Chrome and choose "Add to Home screen" / "Install app".

All attendance data is stored in browser localStorage on the device.
There is no login, backend, cloud sync, analytics, or automatic upload.

Use Settings > Backup regularly because browser storage can be cleared.
